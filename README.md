# ConsultEng Launchpad

Build a professional Norwegian one-page website for a small digital web studio called ConsultEng.

The website should target newly established Norwegian businesses that need a professional website quickly. The main service is: “Profesjonell nettside for nye bedrifter”.

The site should feel like a serious small agency, not a freelancer portfolio, but it should also include a personal credibility section about Benjamin Eng, who runs the studio. Use “vi” in the main service sections, but use “jeg” or “Benjamin” in the about section.

Important style direction:
Create a clean, premium, modern website with a light visual style. It should feel slightly Silicon Valley-inspired, but still trustworthy and approachable for Norwegian small businesses. Take inspiration from high-end consulting websites, especially the clean and polished feel of skrindoconsult.com, but do not copy it.

Avoid generic AI-generated design. The website should not look like a standard template. Keep the design minimal, sharp and custom. Use strong spacing, elegant typography, polished layout, tasteful cards, subtle hover effects and clean section transitions. Do not overuse gradients, abstract shapes, fake dashboards or decorative effects.

Use a light base, lots of whitespace, elegant typography, and a calm premium color palette. Suggested style: white/off-white background, dark text, muted navy/charcoal details, subtle blue or green accent, soft shadows and rounded cards. The site should feel sharp, serious and credible.

Language:
The entire website should be in Norwegian.

Main positioning:
ConsultEng hjelper nye bedrifter med å komme profesjonelt på nett raskt, slik at de fremstår seriøse, forklarer tilbudet sitt tydelig og gjør det enkelt for kunder å ta kontakt.

Technical requirements:
- Fully responsive
- Smooth scrolling
- Fast loading
- SEO-friendly structure
- Use semantic HTML
- Include proper meta title and description
- Make the contact form visually polished, even if backend submission is mocked for now
- Use subtle fade-in on scroll for sections
- Use simple hover effects on cards and buttons, such as slight opacity change, soft shadow increase or minimal upward movement
- Keep all animations calm and restrained
- Avoid flashy movement, bouncing elements, excessive parallax or dramatic transitions
- Make it easy to later connect the form to email or a CRM

Important design warning:
Do not create a generic AI SaaS landing page. Avoid cliché robot/AI visuals, generic gradient blobs, fake dashboards that look unrelated, and overused startup copy. The page should feel custom, calm and credible.
